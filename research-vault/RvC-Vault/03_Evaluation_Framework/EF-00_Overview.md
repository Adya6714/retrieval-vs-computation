# EF-00 Evaluation Framework — Overview

The instrument: three orthogonal probes applied to every instance of a 219-problem bank (GSM 44, BW 65, ALGO 110 = CC/SP/WIS), five models, ~20K calls, per-instance convergence labels. Each probe carries an assumption the others do not share; a label is issued only on agreement.

- [[EF-01_Probe1_Surface_Invariance]] — does the verified answer survive W1–W6?
- [[EF-02_Probe2_Plan_Execution]] — does declared strategy match session-isolated execution; what happens under false-state injection?
- [[EF-03_Probe3_Exposure]] — Infini-gram proximity to public corpora (proxy) + built-in CC/SP/WIS exposure gradient.
- [[EF-04_Convergence_Labels_MTMM]] — labeling logic and its psychometric upgrade path.
- [[EF-05_Metrics_Glossary]] — every metric, formula, and source file.
- [[EF-06_Open_Methodological_Questions]] — what a hostile reviewer attacks, and the fixes.

Pipeline ground truth lives in the repo (README, docs/evaluation/MASTER_EVALUATION_PIPELINES.md, PROBE_PIPELINE_REFERENCE.md). This folder documents the design and its justification, not file paths; cited numbers carry status tags per [[00_MOC]].
