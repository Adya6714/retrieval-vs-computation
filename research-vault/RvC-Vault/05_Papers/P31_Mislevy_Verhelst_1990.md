# P31 Modeling Item Responses When Different Subjects Employ Different Solution Strategies (Mislevy & Verhelst, Psychometrika 1990) — verified-source (foundational, widely cited)
framing: examinees may use different solution strategies; a single IRT model is then misspecified. Introduces mixture IRT — latent classes with class-specific item parameters, membership inferred from response patterns.
measures: class-conditional item difficulties; posterior class membership.
granularity: per-respondent (here: per model×item response bundle).
bears_on: **[[DS-01_Latent_Strategy_Measurement_Model]] — the theoretical foundation.** Also [[EF-04_Convergence_Labels_MTMM]] (this is what "labels" should become).
new_angle: never applied to LLM strategy diagnosis; porting it is the novelty.
