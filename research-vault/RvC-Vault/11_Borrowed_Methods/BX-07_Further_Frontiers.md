# BX-07 — Further Frontiers (more disciplines, briefly, for later mining)

Not yet developed into full probes; logged so the well does not run dry.

**Psychophysics.** SIGNAL DETECTION THEORY separates sensitivity (d′) from bias (criterion) — we already use it for source monitoring; apply it anywhere the model makes a discrimination, to separate "can it tell" from "is it biased." STAIRCASE / ADAPTIVE THRESHOLD methods (titrate difficulty to find the 75%-correct point) → the minimal-perturbation threshold at which each item breaks, an efficient per-item fragility measure (connects [[DS-08_Adaptive_Diagnosis]]).

**Animal cognition.** DELAYED MATCH-TO-SAMPLE, TRANSITIVE INFERENCE (if A>B and B>C, does it infer A>C?), OBJECT PERMANENCE — all designed to test abstraction in minds WITH NO LANGUAGE, i.e. pure process tests that cannot be solved by verbal recall. Ideal templates for language-independent reasoning probes. Transitive inference in particular is a clean computation-vs-lookup test.

**Sociology / network science.** DIFFUSION studies (how behavior spreads through a population) → across a population of models or across fine-tuning generations, how does a fragility or a capability propagate? Connects to [[DS-10_Cross_Model_Transfer_Attack]] and to model-lineage studies.

**Linguistics.** POVERTY OF THE STIMULUS / WUG TEST (Berko 1958: give a novel word "wug," see if the child applies the plural rule → productive rule vs memorized forms). The wug test is almost EXACTLY our nonce-rename probe, from 1958. Cite Berko as deep precedent for W3; generalize to novel-rule application beyond morphology.

**Econometrics / causal inference.** INSTRUMENTAL VARIABLES, REGRESSION DISCONTINUITY, DIFFERENCE-IN-DIFFERENCES → for cleaner causal claims from observational training-data variation when controlled pretraining is too expensive. Method-transfer for the exposure-effect estimation in [[DS-04_Exposure_Variance_Laws]].

Rule for mining: a method qualifies if it was built to infer a HIDDEN property from OBSERVABLE behavior under the assumption that output can mislead. Keep a running list here as you read.
