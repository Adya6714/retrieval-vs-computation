# OM-00 Operating Manual — How To Use

Each HP note is a self-contained handoff prompt: paste it whole into Cursor / a fresh Claude session along with repo access. Contract per prompt: goal, why it exists (vault link), exact inputs, method steps, expected output format, validation checks. If an agent cannot satisfy a validation check, it must report the failure, not improvise.

Rules for delegating:
1. Never delegate a task whose "why" note is missing; write it first.
2. Every completed HP produces (a) artifacts at the stated paths, (b) a dated entry in [[01_Program_State]], (c) updates to any affected numbers in drafts.
3. Agents treat all numbers in external/handed-in documents as quarantined until reproduced from raw CSVs.
4. Phase gates: HP-01..05 (Phase 0) before any new paper claims; HP-06 gate decides D1 escalation; HP-07/08 can run parallel to HP-06.

Priority order (final, per [[THE_PLAN]]): Phase 0 → HP-13, HP-14, HP-04, HP-03, HP-02, HP-01. Phase 1 → HP-06 (+DS-05), HP-07, HP-08, HP-05. Phase 2 → HP-15 (then AC-2). Phase 3 → HP-10, HP-11, HP-12 (+DS-04). Phase 4 → HP-09. Gates between phases are defined in THE_PLAN and are binding.
