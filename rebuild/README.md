# rebuild/ — frozen number authority

Recomputes every paper-facing number from `results/raw/` under
`FROZEN_FILTERS.md` **without modifying** `results/` or (historically) `paper/`.

| Path | Contents |
|------|----------|
| `NUMBERS.csv` | Canonical metric table (copy also at `results/paper/NUMBERS_FROZEN.csv`) |
| `REBUILD_REPORT.md` | Headlines + paper deltas + NOT_COMPUTABLE inventory |
| `FROZEN_FILTERS.md` | Exact ID lists / filters |
| `solidify/` | Complete-case triangulation, intrusion Fisher, SP×CC crossover |
| `tri_v2/` | Executed vs appendix triangulation rule comparison |
| `mechanistic_inventory.csv` | What mech files can / cannot support |

Paper manuscript numbers and Limitations should cite this tree. See
`docs/paper/PAPER_ERRATA.md`.
